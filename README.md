# 報價單生成系統

## 功能說明

這是一個本地運行的報價單生成系統，可以幫助您快速創建專業的報價單並導出為PDF格式。

## 主要功能

1. **公司資訊設定**
   - 公司名稱、地址、電話、統一編號
   - Logo上傳和預覽
   - 發票章圖片上傳和預覽

2. **客戶資訊輸入**
   - 客戶公司名稱
   - 負責人
   - 電話
   - 統一編號

3. **報價單資訊**
   - 報價單編號（自動生成）
   - 報價日期
   - 有效期限

4. **商品管理**
   - 新增/刪除商品
   - 品項、數量、單價輸入
   - 自動計算未含稅金額、稅額（5%）、含稅金額
   - 自動加總功能
   - 支援含稅/未含稅兩種計算方式

5. **備註說明**
   - 可添加備註資訊

6. **PDF生成**
   - 一鍵生成PDF報價單
   - 自動下載功能
   - 包含所有資訊、Logo和發票章

## 使用方法

1. 直接在瀏覽器中打開 `index.html` 文件
2. 填寫公司資訊和客戶資訊
3. 上傳Logo和發票章圖片（可選）
4. 添加商品明細
5. 點擊「生成PDF報價單」按鈕
6. PDF文件會自動下載

## 注意事項

- 本系統使用瀏覽器本地運行，無需安裝額外軟體
- 所有資料僅在瀏覽器中處理，不會上傳到任何伺服器
- 建議使用現代瀏覽器（Chrome、Firefox、Edge等）
- 圖片格式支援：PNG、JPG、GIF等常見格式
- 稅率固定為5%，可選擇含稅或未含稅計算方式

## 技術說明

- HTML5 + CSS3 + JavaScript
- jsPDF 庫用於PDF生成
- jsPDF-AutoTable 用於表格生成
- 響應式設計，支援各種螢幕尺寸
- 所有功能都在瀏覽器本地執行，無需網路連線（首次載入需載入CDN資源）

3. 開始使用！
